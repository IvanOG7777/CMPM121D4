## Target

This game is  a 3D snake game where the player moves a dragon around an enclosed stone map collecting glowing apples. Each apple increases
the dragons length and score by 1. The game uses a smaller 12x12 map with differnt obstacles and layouts, requiring that players avoid walls
and their own body.

## Where things live

The game's rules are stored in the core/ directory, while rendering and player input are handled in the app/ directory.

core/dragon.gd: This file handles dragon movement, growth, and turning.

core/session.gd: Here we take care of food generation, scoring, collisions, and the game's starting and ending conditions.

core/board.gd: Stores the board's tiles and determines whether a tile is solid.

core/kit.gd: This determines which dragon model and rotation should be used for each body segment.

core/level.gd: Finds and loads levels from text files.

app/main.gd: Handles player input, rendering, camera movement, level switching, restarting, and the score display.

app/stage.gd: Handles the environment, lighting, and rendering of the board.

tools/build_art.py: Generates the 3D models using Blender's Python library.

levels/: Contains the text files used to generate each level.

tests/: Contains tests for the game's rules and level parser.

## Adding a tile kind

To add a new tile kind:

Open core/board.gd and add the new tile kind to Board.TILES, specifying whether the tile is solid.

Open tools/build_art.py and create a builder function for the new tile's 3D model.

Register the builder in the TILES dictionary using the same name as the tile kind in core/board.gd.

Open core/level.gd and add a new character to the LEGEND dictionary that represents the new tile.

Add the new character to a text file inside the levels/ directory.

Run deno task art to regenerate the models.

Run deno task dev to check that the tile appears correctly.

Add a test for the new tile's rules and run deno task ci to verify that the changes pass all checks.
